TEXT OVERFLOW

Translated text is often longer/shorter than the source.

Implement adaptive text layout.

If translated text exceeds the original text box:

1. Reflow within available bounds.
2. Adjust line wrapping.
3. Expand block where safe.
4. Rebalance surrounding content.
5. If necessary, create a continuation region/page.
6. Never silently clip text.
