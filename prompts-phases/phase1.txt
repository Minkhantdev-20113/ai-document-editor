AI:
- BYOK architecture
- Gemini as the primary provider
- Provider adapters for Groq, OpenRouter, DeepSeek, and generic OpenAI-compatible APIs
- Do not hard-code provider-specific logic throughout the application.

IMPORTANT ARCHITECTURE RULES

1. Google Apps Script must NOT be used as the heavy PDF-processing engine.
2. Google Sheets must NOT store raw API keys.
3. PDF processing must be asynchronous.
4. Heavy processing must not block the main UI thread.
5. The application must remain usable while AI providers are unavailable.
6. Project state must be persisted locally first.
7. Cloud synchronization must be secondary.
8. The application must be resumable after browser refresh or temporary network failure.
9. Never assume that multiple API keys automatically multiply a provider's quota.
10. Provider rate limits must be treated as provider/account/model dependent.
